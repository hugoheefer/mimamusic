# assets/ — images to upload to Squarespace

`../../website/images/` (full-res originals) and `../../website/images/web/`
(shrunk copies). This file is the manifest: which file goes where. Upload the
full-res originals and let Squarespace resize, unless a file is huge.

If this folder is ever moved out of the repo, copy the files listed below into
this directory and update the paths.
