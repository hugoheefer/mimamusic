NOT COVERED BY URL MAPPINGS (handle separately):

- Bare "/" and "/index.php" with no trailing path: the site root already
  serves the new home page, and Squarespace 301s the non-canonical host
  (www vs non-www) automatically once the domain is connected. The
  "/index.php -> /" rule above catches the explicit form.

- JEvents event URLs (?option=com_jevents&...): these carry query strings,
  which Squarespace URL Mappings cannot match. They will 404 to the custom
  404 page. Acceptable — the live agenda grid is empty, so there are no
  indexed event pages worth saving. If a crawl finds any, add a
  manual redirect for each exact path, or point the 404 page at /agenda.
